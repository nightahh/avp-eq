# AVP EQ

An 8-band parametric equalizer that appears in OBS as an audio filter (Filters > Audio Filters > **AVP EQ**).
Part of Auto Voice Profile: the app measures your voice and room, then fills in the bands for you.
You can also edit every band by hand.

Band types: High-pass, Low-pass, Peak (bell), Low shelf, High shelf, Notch. Plus an output gain.

Built for OBS 31 on Windows x64 (built by GitHub Actions). License: GPL-2.0-or-later (same as the OBS plugin template).
